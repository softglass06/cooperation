# 猜数字小游戏

一个网页版「猜数字」小游戏：程序随机生成一个 1~100 的数字，玩家输入猜测，程序提示「大了 / 小了 / 猜对了」，猜对后显示答案和已用次数。

## 项目说明

- 玩法：玩家在输入框输入一个 1~100 的整数，点「猜」后程序给出反馈，直到猜中为止。
- 实现：HTML + JavaScript（每个功能一个独立网页，可单独打开运行）。
- 三个功能分别由三位组员完成，最后合并到主分支，组成一个完整的小游戏。

## 成员与分工

| 成员 | 角色 | 分支 | 负责文件 |

| cyc | 组长（建仓库、写说明、合并分支） | main | README.md |
| lyh | 功能1：输入与判断 | dev-lyh-功能1 | feature1_guess.html |
| yxr | 功能2：计分与次数 | dev-yxr-功能2 | feature2_score.html |

## 分支规范

- 分支命名：`dev-姓名-功能`，例如 `dev-lyh-功能1`。
- 每个成员从最新的 main 拉取，新建自己的分支，只提交自己的文件，然后 push。
- 组长依次把各成员分支合并到 main。

## 功能说明

- 功能1（lyh）：玩家输入数字，程序判断并提示「大了 / 小了 / 猜对了」。
- 功能2（yxr）：记录并显示已猜次数 / 得分。
- 功能3（fzy）：提供「重新开始」按钮和范围提示（例如「范围 1~100」）。
